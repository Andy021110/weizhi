# 主题消歧方案（解决「输入模糊」）

> 日期：2026-08-20 · 状态：已实现 + 测试通过

## 问题

用户建计划输模糊主题（如「经典 Agent 范式」），AI 一次性理解可能切偏（切到经典教材而非 LLM Agent）。根源：AI 一次性理解、无确认环节。

## 方案（组合拳）

**① Prompt 消歧铁律（PLAN_OUTLINE_SYSTEM）**
- 加铁律：服务对象是 AI 从业者，主题默认按 LLM/大模型/现代 AI 语境理解，除非明确指向经典教材/通用概念。
- 作用：解决「语境明确的词」（Agent→LLM）。零成本。

**② 方向确认（DISAMBIGUATE + /api/plan/disambiguate）**
- 建计划流程：输主题 → 先调 disambiguate 判断歧义 → 有歧义弹 2-3 个候选方向（用户点选）→ 按「原主题：方向」出大纲；无歧义直接出大纲。
- 只在 AI 判断有歧义时才多一步点选，清晰主题无感直出。
- 前端：disambigBox 候选区；选方向后拼 `主题：方向label` 再出大纲；「都不是，修改主题」回退。

**④ 兜底**：「重新拆解」按钮重新走消歧流程；planInput 可随时改主题。

## 测试结果（8 case）

| 主题 | 歧义 | 判定 |
|---|---|---|
| 经典 Agent 范式 | ✅ True | LLM Agent vs 经典 AI Agent 分类 |
| 注意力 | ✅ True | LLM 注意力 vs 经典注意力 |
| 向量数据库 | ⚠️ True | LLM 向量库 vs 经典向量索引（略过度，可接受）|
| 奇异值分解 | False | 数学概念明确 |
| Transformer 原理 | False | 已修正（初版误判）|
| RAG 检索增强 | False | 已修正（初版误判）|
| 雅思核心词汇 | False | **已修正 badcase**（初版误判成 AI 术语）|
| 六级高频词 | False | 语言考试词汇 |

## 复盘发现与修正

- **Badcase 1（已修）**：初版 DISAMBIGUATE 的「AI 从业者语境优先」铁律导致「雅思核心词汇」被硬套成 AI 术语。修正：消歧时尊重用户输入的自然含义，明确指向非 AI 内容（雅思/六级/托福）不套 AI；只有主题本身在 AI 语境下天然有歧义才列 AI 方向。
- **Badcase 2（已修）**：「Transformer 原理」「RAG 检索增强」初版过度消歧。同上修正。
- **权衡**：「向量数据库」这类 AI 语境下基本明确但 AI 造出经典方向的主题，会多弹一次候选——接受（宁可多确认一次，不切错）。
- **成本**：每次建计划多一次轻量 AI 调用（temperature=0.3），清晰主题也调——可接受，暂不优化。
- **未测**：前端真实交互（候选弹窗/点选/出大纲）需用户真机验证；t4/t5 模板消歧逻辑通用未单独测。
