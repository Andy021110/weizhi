# 微知 · 产品定位与内容策略

> 制定日期：2026-08-19 · 本文是微知的「北极星」：服务谁、解决什么、内容做什么。
> 其他方案文档（学习计划、生产配方、复盘）都围绕本文收敛，冲突时以本文为准。

---

## 一、一句话定位

> **微知 = 给 AI 从业者的「碎片化持续学习 + 记忆系统」**：用碎片时间，既懂前沿、又懂原理、还不忘，保持学习和探索的心。

不是「求职突击工具」，也不是「泛科技资讯流」，而是**长期的、服务于好奇心和竞争力的学习伙伴**。

---

## 二、目标用户画像

- 互联网公司 AI 相关岗位从业者 / 准从业者（不限于 AI 产品经理，含策略、算法、运营等）
- **技术 + 产品复合背景**：有 CS/AI 技术底座，能读论文、懂代码、不怵公式，同时有产品 sense
- 需要持续追踪 AI 快速演进，保持竞争力和探索欲
- 每天只有 5–10 分钟碎片时间
- 动机：**不落伍 + 有深度 + 保持好奇**（非应试、非功利）

---

## 三、目标用户需求（4 条）

1. **不落伍**：AI 变化极快，持续追踪前沿（模型 / Agent / 多模态 / 工具 / 行业动态）。
2. **有深度**：不止知道「发生了什么」，还要懂「为什么重要、原理是什么」。
3. **可迁移**：学的东西能在工作 / 思考里用上，不是百科堆积。
4. **不忘**：碎片学习配复习巩固（SM-2 间隔重复），学了记得住。

---

## 四、5 类内容主题池（技术+产品并重，前沿+原理平衡）

| 模板 | 主题池 | 具体示例 |
|---|---|---|
| **T1 词汇** | AI 高频术语（技术+产品各半） | 技术：hallucination、grounding、inference、fine-tuning、RLHF、MoE、context window、latency；产品：retention、churn、north star metric、PMF、GTM |
| **T2 精读** | 深度文章/论文（前沿+原理） | 原理：Attention is All You Need、Scaling Laws、RLHF(InstructGPT)、RAG 原始论文；前沿：Agent 架构、多模态、世界模型；商业：a16z/红杉 AI 报告、OpenAI/Anthropic 官方博客、竞品拆解 |
| **T3 数学** | ML 数学底座 | 概率：贝叶斯、KL 散度、熵、最大似然；线代：SVD、特征值、PCA；优化：梯度下降、Adam、凸优化；信息论：交叉熵、互信息 |
| **T4 通识** | AI 行业认知/冷知识 | 历史：图灵测试、深度学习三巨头、AI 冬天、Transformer 诞生；商业：ChatGPT 爆发始末、开源 vs 闭源、AI 芯片之争 |
| **T5 技能** | AI 从业者实操 | 产品：写 PRD、竞品分析、AB test、用户访谈；技术：Cursor/v0 快速原型、Prompt 技巧、RAG 搭建、评测体系(Badcase 归因) |

> 主题池原则：**每条主题都能在面试 / 工作 / 思考里用上**；前沿与原理各占一半，技术与产品各占一半。

## 五、完成边界（做什么 / 不做什么）

**做（核心主线）：**
- AI 稳定生成高质量结构化学习卡片（生产配方 + golden set + 字段校验）
- 切片算法（主题 → 原子单元 → 卡片）
- 复习引擎（SM-2，学了不忘）

**不做 / 暂停（避免越做越乱）：**
- 图文卡（SVG/位图）—— 与主线无关，砍
- 预设任务库 —— 自定义主题已够，砍
- APK 打包 —— 网页版自用够，暂停
- 搜索/收藏/统计等边缘功能 —— 已有基础版，停止继续投入

**完成定义：**
> 微知做到「每类有 golden set 兜底、抽 20 张卡无硬伤、每天愿意打开学 3 张」即算完成。此后只维护，不加新功能。
