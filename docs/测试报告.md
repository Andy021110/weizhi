## 二、发现的漏洞与修复

### 🔴【P0 已修复】坏卡导致渲染异常 / 无法完成
- 卡 `[0]`「番茄工作法」：无 body / quiz / open_question → 打开后空白正文且**无法标记完成**
- 卡 `[8]` vocab：`title=null`、无 body/title/summary → 空卡
- 卡 `[7]`「贝叶斯定理」：无 body → 阅读内容缺失
- **处置**：新增 `/api/delete` 接口，已删除这 3 张。剩余 18 张**全部有正文、全部可完成**。

### 🔴【P0 已修复】连击状态机「重载覆盖本地进度」
- 原 `applyServerState` 在服务器返回空 `done`（`{}`）时，会用空对象**覆盖本地已读记录**，导致刷新/重开 App 后已读和连击丢失。
- **修复**：改为**合并**逻辑——服务器进度并入本地、本地独有进度保留；连击取较大值。现重载不再丢进度。

### 🟡【P1 已修复】无测验且无简答题的卡无法完成
- 原详情页只有「做测验」「提交评分」两个完成入口；若卡片两者皆无则永远无法标记完成。
- **修复**：详情页增加「✓ 标记已读」兜底按钮，保证**每张卡都可完成**。

### 🟢【P2 待优化】简答评分仅覆盖 T2 类
- 当前 13/18（72%）卡片有简答题；T1 词汇 / T3 数学 / T4 通识 / T5 技能 模板本身未产出 `open_question`。
- 影响：这几类卡只能做选择题、没有 AI 简评。
- 建议：给 T1/T3/T4/T5 模板补 `open_question` 字段（下个迭代）。

### 🟢【P2 待优化】无每日自动生成
- 目前仅 `2026-08-13` 一天数据，cron 未配置，不会自动出新卡。
- 建议：配 crontab 每天 06:00 跑 `pipeline.py`（消耗 DeepSeek 额度，约每日几毛钱）。

### 🟢【P2 待优化】内容源偏科技
- 18 张里 12 张来自科技类 RSS（少数派 / 阮一峰 / HN / MIT）；通识 / 人文 / 影视偏少。
- 建议：补充人文、通识、影视类 RSS 源（config.example.json 已含，待启用）。
