## 关于文档里的模块路径

2026-09-12 做过一次目录重构：23 个运行时模块从仓库根目录收进了 `weizhi/` 包，按职责分四层。**在此之前写的文档里出现的模块名是旧的扁平路径**，我们没有回改它们——那会变成篡改当时的记录。对照如下：

| 文档里写的 | 现在的位置 |
|---|---|
| `pipeline.py` `evidence.py` `card_writer.py` `news.py` `visual.py` `bridge_v1.py` `assessment.py` `card_gates.py` | `weizhi/produce/` |
| `reader.py` `review_flow.py` `mastery.py` `planner.py` `goalspec.py` | `weizhi/serve/` |
| `db.py` `providers.py` `schema_v2.py` `prompts.py` `notifications.py` | `weizhi/core/` |
| `daily_check.py` `daily_agent.py` `revisions.py` `v2_shadow.py` | `weizhi/ops/` |
| `reader.html` `manifest.json` `sw.js` `icon-*` | `weizhi/serve/web/` |
| `deploy.py` `deploy.sh` `weizhi-reader.service` `nginx.conf` | `deploy/` |

入口命令也跟着变了，从 `python pipeline.py` 改成 `python -m weizhi.produce.pipeline`。当前的结构与决策以[仓库根的 ARCHITECTURE.md](../ARCHITECTURE.md) 为准。
