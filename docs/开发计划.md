## 零、鉴权方案（无感，最优先）

**目标**：防陌生人白嫖，但用户日常完全无感。

**做法**：
1. 生成一个随机 token（如 `WeiZhi-2026-xxxxxxxx`）存到服务器 `config.json`。
2. `reader.py` 加轻量校验：所有请求需带 token（从 URL `?key=` 或 header 读）。
3. 前端首次访问「带 key 的 URL」→ 把 key 存 `localStorage` → 之后所有请求自动带 token。
4. 用户日常：书签/桌面图标存「带 key 的 URL」，**打开即用，完全无感**。
5. APK：内置 token，**完全无感**。
6. 换设备/清缓存：重新用「带 key 的 URL」访问一次即可。

> 一句话：第一次配置一次，之后和现在一样直接打开。

## 一、分阶段开发

### P0 · 安全止血（鉴权 + 每日配额）｜ 30-40 分钟

| 任务 | 内容 | 涉及文件 |
|---|---|---|
| 鉴权 | token 校验中间层 + 前端 localStorage 持久化 | reader.py / reader.html / config.json |
| 生成上限 | 每天最多生成 ≤15 张新卡 | pipeline.py / config.json |
| 推送上限 | 每天最多展示 ≤15 张新卡 | reader.py |
| 部署验证 | 部署 + 实测 | — |

**验收**：陌生人访问被拦；每天生成 ≤15；每天展示 ≤15。

### P1 · 计划系统最小闭环｜ ~1 天

| 任务 | 内容 |
|---|---|
| 数据层 | plans 表 + cards 加 plan_id/plan_index/plan_total（migrate） |
| 后端 | /api/plans CRUD + /api/plan/create（AI 拆大纲 → 批量生成卡） |
| 前端 | 建计划页、计划列表、进度徽章、续学优先 |

**验收**：能建计划 → AI 拆大纲（可预览/删改）→ 批量生成 → 续学优先 → 徽章标识。

### P2 · 复习引擎（SRS）｜ ~1 天

| 任务 | 内容 |

**验收**：复习队列正确；SM-2 间隔（1→3→7→15→30）正确；答错回退 1 天。

### P3 · 短期任务 + 统计 + 增强｜ ~半天

## 二、依赖关系

```
P0（独立，先做）
  ↓
P1（依赖 P0 的鉴权 + 数据层）
  ↓
P2（依赖 P1 的计划，复习针对任务卡）
  ↓
P3（依赖 P1/P2）
P4（可与 P1 并行，内容侧独立）
P5（依赖 P0 鉴权，前端稳定后打包）
P6（依赖 P1 计划系统，是 P1 的切片升级，可与 P2 复习引擎并行）
```

## 三、贯穿性事项（每个阶段都留意）

- 状态机数字同源（连击/进度/复习状态，刷新不丢）
- 出错降级（AI 超时/失败不白屏）
- 部署后热更新验证（刷新即生效，除非壳级改动）
